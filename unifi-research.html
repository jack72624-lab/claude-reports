Knowledge Base
核心概念解析

入手 UniFi 前必須了解的關鍵技術名詞

⚡

PoE — 網路供電

Power over Ethernet，一條網路線同時傳輸資料與電力。PoE 15W → PoE+ 30W → PoE++ 90W，AP / 攝影機 / 門禁設備免拉電源線。

🖥️

UniFi OS Console

Dream Machine / Cloud Gateway 內建的作業系統，統一管理 Network / Protect / Access 三個 App，不需另外買 Cloud Key。

🌈

Etherlighting™

Pro Max / XG 系列 Switch 專有功能，每埠旁都有可自訂顏色的 LED，可顯示埠速度、狀態或自訂燈效。

🔗

SFP / SFP+ / SFP28

光纖或銅線上行模組插槽。SFP = 1G、SFP+ = 10G、SFP28 = 25G、QSFP28 = 100G，用於長距離或高速骨幹連線。

📶

WiFi 7 vs 6E vs 6

WiFi 7 = 最新（6 GHz + MLO 多連結）；WiFi 6E = 上一代（也有 6 GHz）；WiFi 6 = 成熟主流。家用選 U7 Lite，辦公選 U7 Pro。

🗺️

VLAN 隔離

同一實體網路上建立多個虛擬隔離網段。員工 / 訪客 WiFi / IoT / 監控各自隔離，大幅提升安全性。

🔀

Layer 2 vs Layer 3

L2 Switch 轉發 MAC 位址；L3 Switch 支援 IP 路由，不同 VLAN 間可直接通訊，不需額外 Router。Enterprise 系列支援 L3。

☁️

Site Magic / UniFi Cloud

免費雲端遠端管理，無需 VPN 或公網 IP。從 unifi.ui.com 全球任何地方管理所有設備，適合多據點部署。

Before You Buy
購買與部署注意事項

從官方授權店購買前必看的重點提醒

🔑

需要 UI Account

所有 UniFi 設備都需要 Ubiquiti 帳號才能完成初始設定。雲端管理完全免費，本地 Console 也支援離線操作。

📦

Gateway 是必要的起點

UniFi 生態的核心。若已有其他廠牌路由器，AP 和 Switch 仍可加入，但需自行架設軟體 Controller（不推薦）。

💡

計算 PoE Budget

Switch 的 PoE Budget（如 400W）是所有 PoE 設備的總用電上限。AP 約 15–25W，攝影機約 10W，部署前要加總確認。

🔄

Protect 需要 NVR 才能錄影

攝影機必須搭配 NVR（UNVR / ENVR）或有 NVR 功能的 Console（UDM-Pro-Max 等）。單獨買攝影機沒辦法錄影。

🏗️

建議部署順序

① Gateway → ② PoE Switch → ③ AP 接 Switch → ④ 攝影機 / 門禁最後。每台設備上電後 App 自動偵測，流程順暢。

📱

手機 App 管理

iOS / Android 均有 UniFi Network、Protect、Access 三個 App，支援遠端推播通知、設備重啟、即時設定修改。

🌐

台灣正貨保固

官方授權店提供在地保固與技術支援。UniFi 韌體更新頻繁，水貨缺乏保固，建議優先正貨購買。

⚠️

注意授權與訂閱

部分進階 IDS/IPS 規則、多站點進階功能可能需要 UniFi Enterprise 授權。一般家用和 SMB 場景通常免費功能就夠用。
