💡 核心概念與技術解析
入手 UniFi 前必須了解的關鍵技術
⚡

PoE — 網路供電

Power over Ethernet，透過網路線同時傳輸資料與電力。AP、攝影機、門禁設備不需額外電源線。PoE (15W) → PoE+ (30W) → PoE++ (90W) 三種規格。

🎮

UniFi OS Console

Dream Machine / Cloud Gateway 都內建 UniFi OS，是管理所有 UniFi 應用程式（Network/Protect/Access）的統一作業系統，不需額外 Controller。

🌈

Etherlighting™

Pro Max / XG 系列 Switch 專有功能，每個網路埠旁都有 LED 指示燈，可自訂顏色顯示埠狀態、速度或自訂效果。

🔗

SFP / SFP+

光纖或銅線上行模組插槽。SFP = 1G，SFP+ = 10G，SFP28 = 25G，QSFP28 = 100G。長距離或高速骨幹連線使用。

🏠

WiFi 7 vs WiFi 6E vs WiFi 6

WiFi 7 = 最新（6 GHz + MLO 多連結操作）；WiFi 6E = 上一代（也有 6 GHz）；WiFi 6 = 成熟主流（2.4/5 GHz）。家用選 WiFi 7 Lite 或 U6+，辦公選 U7 Pro。

🗺️

VLAN 劃分

在同一物理網路上建立多個隔離的虛擬網路，例如：員工網路、訪客 WiFi、IoT 設備、監控系統各自隔離，提升安全性。

🔀

Layer 2 vs Layer 3

L2 Switch = 一般交換器，轉發 MAC 位址；L3 Switch = 可做 IP 路由，不同 VLAN 間不需另外加 Router。Enterprise 系列支援 L3。

📊

Site Magic / UniFi Cloud

免費雲端遠端管理，無需 VPN 或公網 IP。透過 unifi.ui.com 即可從全球任何地方管理所有 UniFi 設備，適合多據點部署。

🔑

需要 UI Account

所有 UniFi 設備都需要 Ubiquiti 帳號才能設定。雲端管理不需額外費用，本地 Console 也可離線運作。

📦

Gateway 是必要的

UniFi 生態的起點是 Cloud Gateway。若已有其他廠牌路由器，AP/Switch 仍可以加入，但管理功能會受限（需自行架 Controller）。

💡

PoE 預算計算

Switch 的 PoE Budget（如 400W）是所有 PoE 設備用電的總上限。AP 約 15~25W、攝影機約 10W，部署前需計算總需求。

🔄

Protect 需要 NVR 或 Console

攝影機必須搭配 NVR（UNVR/ENVR）或有 NVR 功能的 Console（UDM-Pro-Max 等）才能錄影。單獨買攝影機無法錄影。

🌐

台灣正貨保固

台灣官方店購買提供在地保固與技術支援，建議避免水貨，Ubiquiti 的韌體更新頻繁，在地保固很重要。

🏗️

部署順序建議

① 先裝 Gateway → ② 接 PoE Switch → ③ AP 接 Switch → ④ 攝影機/門禁最後部署。每個設備上電後 App 自動偵測。

📱

UniFi App 手機管理

iOS / Android 都有 UniFi Network、UniFi Protect、UniFi Access 三個 App，支援遠端即時推播通知、設備重啟、設定修改。

⚠️

非住宅用途授權

部分企業功能（如進階 IDS/IPS 規則、多站點管理）可能需要 UniFi Enterprise 授權，請確認使用場景是否需要額外訂閱。
