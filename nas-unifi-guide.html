Part 1 · 基礎概念

NAS 是什麼？

Network Attached Storage，直譯「網路附加儲存」。簡單說就是一台接在網路上的共用硬碟，全家或公司的人都能存取，還能自動備份。

🌐

為什麼要接網路？

普通外接硬碟只能接在一台電腦。NAS 接在網路上，任何裝置（電腦、手機、電視）都能直接連進去取檔案，甚至在外面用網路也能存取。

🔵

UniFi 在這裡做什麼？

UniFi 是管理整個網路的系統，負責讓 NAS 有穩定的固定 IP、隔離安全網段、設定誰可以存取 NAS、以及建立安全的遠端連線通道。

🏠

常見 NAS 品牌

Synology（群暉）最易用，介面像 Windows；QNAP（威聯通）功能強大；TrueNAS 開源免費。本教學以 Synology 為主要範例。

🔌

NAS 需要 PoE 嗎？

不需要。NAS 有獨立的電源變壓器，自己插電。它只需要一條網路線接到 UniFi Switch 的任意埠，普通埠或 PoE 埠都可以。

📁

NAS 能做什麼？

檔案共享、相片自動備份、影片串流、Docker 跑應用程式、監控錄影備份、Time Machine（Mac 備份）、甚至架設私有雲端。

Part 3 · 安全隔離
VLAN 是什麼？為什麼 NAS 需要它？

不做 VLAN 也能用，但做了之後安全性大幅提升。這一段解釋原理，不需要現在就設定。

⚠️ 沒有 VLAN 的問題：如果你家的智慧燈泡、電視、NAS 全部在同一個網路，一旦任何一個 IoT 設備被入侵，攻擊者就能直接存取 NAS 裡的所有資料。
✅ VLAN 設定後的網路分區（點擊各區域查看說明）

🏠 主網段 VLAN 1

  • 個人電腦
  • Mac / iPad
  • 可信任裝置

📦 NAS 專屬 VLAN 10

  • Synology NAS
  • 備份裝置
  • 僅主網段可存取

💡 IoT 設備 VLAN 20

  • 智慧燈泡
  • 智慧插座
  • 電視 / 串流盒

🌐 訪客 WiFi VLAN 99

  • 訪客手機
  • 臨時裝置
  • 完全隔離
點擊上方任一網段，查看該網段的存取規則說明。
✅ 總結：IoT 設備和訪客 WiFi 無法直接存取 NAS。只有主網段（你的電腦、手機）才能連進去。就算智慧燈泡被入侵，攻擊者也碰不到 NAS。

🔧 操作步驟

  • 準備一條 Cat 5e 或 Cat 6網路線規格，Cat 5e 支援 1Gbps，Cat 6 支援 10Gbps。一般 NAS 用 Cat 5e 就夠，若 NAS 有 2.5G 網口則建議 Cat 6。 網路線
  • 一端接 NAS 的 LAN 埠（一般在機器背面）
  • 另一端接 UniFi Switch 的任意埠（PoE 或非 PoE 都可以）
  • 接好後開機，等待 NAS 啟動（約 2–3 分鐘）
💡 NAS 有自己的電源，網路線只負責傳輸資料，不提供電力。不要接 WiFi，有線才能保證穩定速度。
2

找到 NAS 的 IP 位址

確認 NAS 已成功加入網路

▾

📱 方法一：UniFi App 查看（推薦）

  • 開啟手機 UniFi Network App
  • 進入 Clients（客戶端） 清單
  • 找到 NAS 的 MAC Address每個網路設備都有的唯一識別碼，格式像 AA:BB:CC:DD:EE:FF，通常印在 NAS 底部的標籤上。（貼在機器背面）
  • 即可看到 Gateway 自動分配的 IP，例如 192.168.1.105

🖥️ 方法二：Synology Assistant 軟體

  • 在電腦下載並安裝 Synology Assistant（官網免費）
  • 它會自動掃描區域網路，找到 NAS 並顯示 IP
  • 或直接瀏覽器輸入 find.synology.com
⚠️ 這個 IP 目前是 DHCPDynamic Host Configuration Protocol，動態主機設定協定。路由器自動分配 IP 的機制，每次重新開機 IP 可能會變。 自動分配的，下次重開機可能會變。Step 3 我們會把它固定住。
3

設定固定 IP（DHCP Reservation）

讓 NAS 每次開機都有同樣的 IP，這樣書籤和設定不會失效

▾
💡 為什麼要固定 IP？如果 NAS 的 IP 一直變，電腦上設定的「網路磁碟機」路徑就會失效，每次都要重新找 IP 很麻煩。

🔧 在 UniFi Network 設定 DHCP Reservation

  • 開啟 UniFi Network App 或 unifi.ui.com
  • 點選左側 Clients → 找到 NAS
  • 點選 NAS，進入裝置詳情頁
  • 找到 「Fixed IP」 或 「IP Address Reservation」
  • 輸入想要固定的 IP，例如 192.168.1.200
  • 點 Apply，重啟 NAS 後生效

💡 建議的 IP 命名規則

  • 192.168.1.200 — Synology NAS 主機
  • 192.168.1.201 — 第二台 NAS（如有）
  • 建議 .100 以後的 IP 留給固定設備，前面留給 DHCP 動態分配
4

建立 NAS 專屬 VLAN（進階，強烈建議）

把 NAS 隔離在獨立網段，大幅提升安全性

▾
⚠️ 這步稍微複雜，做完後設定也需要調整。如果客戶是一般家庭，可先跳過。如果是商業環境或有 IoT 設備，強烈建議做。

① 建立新的 Network（網段）

  • UniFi Network → Settings → Networks → Add New Network
  • Name: NAS-Storage
  • VLAN ID: 10（自訂，不與其他衝突即可）
  • Gateway IP: 192.168.10.1
  • DHCP 開啟，範圍: 192.168.10.100 – 192.168.10.199

② 把 NAS 連接的 Switch 埠指定到這個 VLAN

  • UniFi Network → Devices → 點選你的 Switch
  • 找到 NAS 接的那個埠（例如 Port 8）
  • 點選 Port 8 → Profile → 選擇 NAS-Storage Network
  • 設為 Untagged (Access Port)Access Port：這個埠只能屬於一個 VLAN，連接的設備（NAS）不需要知道 VLAN 的存在，網路會自動處理標籤。適合連接 NAS、電腦等終端設備。

③ 給 NAS 設定新的固定 IP

  • NAS 移到 VLAN 10 後，IP 會變成 192.168.10.x
  • 同樣做 DHCP Reservation，固定在例如 192.168.10.200
5

設定防火牆規則（搭配 VLAN 使用）

控制哪些網段可以存取 NAS，哪些不行

▾
💡 做完 VLAN 隔離後，預設情況下各 VLAN 之間無法互通。我們需要加一條規則：允許「主網段」的裝置存取「NAS VLAN」。

🔧 在 UniFi 建立防火牆規則

  • UniFi Network → Settings → Firewall & Security → Rules
  • 點 Add New Rule
# 規則 1：允許主網段存取 NAS Name: Allow-Main-to-NAS Action: Accept Protocol: All Source Network: 主網段 (VLAN 1) Destination: 192.168.10.200 (NAS 的 IP) # 規則 2：阻擋其他 VLAN 存取 NAS Name: Block-Others-to-NAS Action: Drop Protocol: All Source: Any Destination: 192.168.10.200
規則按順序執行：先符合規則 1 的允許，其餘全 Drop
網段能存取 NAS？說明
🏠 主網段 (VLAN 1)✓ 允許你的電腦、手機
💡 IoT (VLAN 20)✗ 封鎖智慧燈泡、電視等
🌐 訪客 WiFi (VLAN 99)✗ 封鎖訪客裝置
6

驗證設定是否成功

確認電腦能連到 NAS，手機 App 也能正常使用

▾

🖥️ 從電腦連線測試

  • 瀏覽器輸入 NAS IP：http://192.168.1.200:5000（Synology DSM 預設埠）
  • 應該出現 Synology DSM 登入頁面 ✅

📂 掛載網路磁碟機（Mac）

  • Finder → 前往 → 連接伺服器
  • 輸入：smb://192.168.1.200
  • 輸入 NAS 的帳號密碼，就能看到共用資料夾

📂 掛載網路磁碟機（Windows）

  • 檔案總管 → 本機 → 右鍵 → 連線網路磁碟機
  • 資料夾輸入：\\192.168.1.200\共用資料夾名稱
✅ 設定完成！NAS 已穩定接入 UniFi 網路，有固定 IP，有安全隔離，有防火牆保護。
Part 5 · 遠端存取
在外面也能存取 NAS

離開家或辦公室後，想連回 NAS 有三種方法，各有優缺點。

方法 安全性 設定難度 速度 適合對象 說明
🔒 UniFi VPN 最高 中等 普通 進階用戶 用 UniFi 內建 WireGuard VPN現代化 VPN 協定，速度快、設定簡單，比舊版 OpenVPN 效能好很多。UniFi 已內建，不需要額外的 VPN 伺服器。，手機連 VPN 後就像在家一樣存取 NAS
☁️ Synology QuickConnect 中等 最簡單 普通 一般用戶 Synology 官方中繼服務，不需要固定 IP，App 設定好就能用，但流量經過 Synology 伺服器
🌐 Port Forwarding 較低 中等 最快 進階用戶 直接在 Gateway 開一個 Port連接埠，像是網路的「門牌號碼」。一個 IP 有 65535 個 Port，不同服務用不同 Port，例如網頁用 80/443，NAS 管理介面用 5000/5001。 對外，速度最快但暴露較多，需搭配強密碼和 2FA

🔧 推薦：設定 UniFi WireGuard VPN（給進階用戶）

  • UniFi Network → Settings → VPN → VPN Server
  • 選擇 WireGuard，點 Create New
  • 設定名稱、VPN 子網段VPN 連線的客戶端會被分配到這個網段的 IP，例如 10.6.0.0/24，與家庭網路分開但可以互通。（例如 10.6.0.0/24）
  • 建立完成後，匯出 .conf 設定檔 或 QR Code
  • 手機安裝 WireGuard App，掃描 QR Code 匯入，開啟 VPN 就完成
💡 連上 VPN 後，你的手機就像在家裡一樣，可以用 192.168.1.200 直接存取 NAS，完全加密，最安全。
Part 6 · 常見問題
客戶最常問的問題

點擊問題展開答案。

Q
NAS 要幾個硬碟？買什麼規格？
▾
最少 2 顆，可以設定 RAID 1（鏡像）RAID 1 = 兩顆硬碟存完全相同的資料，一顆壞掉，資料不會遺失。缺點是可用容量只有總容量的一半（2 × 4TB = 只能用 4TB）。，一顆壞掉不會失去資料。

建議買 NAS 專用硬碟（如 Seagate IronWolf、WD Red），比桌上型硬碟更耐久，設計成 24 小時運轉。容量視需求，家用 2 × 4TB 通常夠用，商業可考慮 2 × 8TB 以上。
Q
NAS 會影響網路速度嗎？
▾
在區域網路內不會影響對外網速。NAS 跟其他電腦傳檔案走的是 Switch 的內網頻寬（1Gbps），不走對外的 WAN。只有遠端存取時才會占用上傳頻寬。

如果 NAS 有多個使用者同時在上傳/下載大檔案，可能影響同一個 Switch 上的流量。建議 NAS 接在有 QoSQuality of Service，服務品質設定，可以設定不同類型流量的優先順序，例如讓視訊會議優先於 NAS 備份。 功能的 Switch 以確保優先級。
Q
斷電後 NAS 會自動開機嗎？
▾
大部分 Synology / QNAP NAS 支援 「斷電後自動重啟」功能。在 NAS 的控制台 → 硬體設定 → 開啟「恢復供電後自動開機」即可。

另外建議搭配 UPS（不斷電系統）Uninterruptible Power Supply，停電後提供短暫電力讓設備安全關機，避免突然斷電損壞資料或硬碟。，停電時可讓 NAS 安全關機，避免硬碟損壞。
Q
手機的照片怎麼自動備份到 NAS？
▾
Synology：安裝 Synology Photos App（iOS / Android），登入後開啟自動備份，家用 WiFi 連到同一個網路就會自動上傳。

QNAP：使用 Qfile 或 QuMagie App 同樣效果。

好處：不占 iCloud / Google Photos 空間，自己的伺服器資料隱私有保障。
Q
NAS 的 IP 如果設定在 VLAN 10，Mac 還能 Time Machine 備份嗎？
▾
可以，但需要設定防火牆允許規則讓 Mac 所在的主網段（VLAN 1）能存取 NAS VLAN（VLAN 10）的 Port 548AFP (Apple Filing Protocol) 用的連接埠，也是 Time Machine 備份用的通訊協定。現代也可以改用 SMB（Port 445）。（AFP）或 Port 445（SMB）。UniFi 防火牆規則在 Step 5 已說明如何設定。
Q
NAS 有安全風險嗎？怎麼保護？
▾
有風險，但可控。建議以下幾點：

① 不要對外直接開放 NAS 管理埠（5000/5001），用 VPN 取代 Port Forwarding
② 開啟 2FA（兩步驟驗證），帳號被盜也沒用
③ 定期更新 DSM 系統，Synology 有持續發布安全修補
④ VLAN 隔離，不讓 IoT 設備接觸到 NAS
⑤ 定期異地備份（3-2-1 備份原則：3 份備份、2 種媒介、1 份異地）
