Chapter 01

認識智能家庭

智能家庭（Smart Home）是把家中設備透過網路串在一起，讓你能用手機、語音，甚至自動排程去控制它們。

  1. 控制
  2. 自動化
  3. 整合
核心 1 · 控制隨時隨地操作設備。用手機 App、語音指令、牆上的面板都可以。以前回家要一個一個手動開燈，現在一句話。
核心 2 · 自動化設定條件，設備自己動作。走進門燈自動亮；出門一個按鈕，全屋關燈、鎖門、空調關閉，同時完成。
核心 3 · 整合不同品牌的設備能互相溝通、聯動。單一設備不是智能家庭，設備彼此能感知、聯動才是。

重點觀念：智能家庭的核心是「互聯」與「自動化」。三個核心缺一不可。

設備分類

常見智能家庭設備分類

照明系統

智能燈泡、智能開關、調光器、燈帶。最常見的入門設備，改裝簡單、效益立竿見影。

環境控制

空調控制、電動窗簾與捲簾馬達。

安全監控

智能門鎖、門磁感應器、動作感應器、攝影機、煙霧偵測器。

02 Chapter 02

Apple HomeKit

訊號的第二站：手機按下去之後，指令先到這裡。

  • 是架構，不是 App家庭 App 是介面；HomeKit 是背後讓不同品牌配件協作的技術基礎。
  • Home Hub 是門檻遠端控制、自動化、安全錄影都要有 Apple TV 或 HomePod 在家。
  • 自動化才是智能情境要手動按；自動化是條件到了設備自己動。
02 · What it is

家庭 App 是介面，HomeKit 是架構

  1. 家庭 App（介面）
  2. HomeKit（架構）
Layer 1 · 家庭 AppiPhone 上的「家庭」App 是操作介面。新增配件、分配房間、建立情境、從控制中心一滑就到，都在這裡。很多人把它跟 HomeKit 搞混。
Layer 2 · HomeKitHomeKit 是 Apple 打造的智能家庭架構（Framework），不是單一 App。它讓不同品牌的相容配件，在同一個安全、私密、易用的平台上和諧協作。

隱私核心：裝置間通訊全程端對端加密（E2E），除了你沒有人能讀，包括 Apple。不依賴雲端、不強制註冊帳號、不追蹤行為。所有認證配件都通過 MFi 審核。

02 · Foundations

打造 HomeKit 智能家庭的三大基石

  1. iPhone / iPad
  2. Home Hub
  3. HomeKit 配件
基石 1 · iPhone / iPad內建的「家庭 App」就是你的控制中心。新增配件、分配房間、建立情境，並透過「控制中心」一滑即達常用設備。
基石 2 · Home Hub由 HomePod、HomePod mini 或 Apple TV 擔任。它是啟用遠端控制與自動化的大腦，同時也是 Thread Border Router（第四章會講），大幅提升設備穩定性。
基石 3 · HomeKit 配件認明包裝上的「Works with Apple Home」標章。代表通過 Apple 認證，相容性與安全性都有保證。
02 · Home Hub

家裡有沒有 Home Hub，差在哪

不需要 Home Hub 也能控制設備，在同一個 Wi-Fi 下就行。但要遠端控制、自動化、HomeKit 安全錄影（HKSV），就必須至少有一台 Home Hub。切換看看：

  • 同一 Wi-Fi 下，用家庭 App 控制設備 可以
  • 遠端控制 可以
  • 自動化 可以
  • HomeKit 安全錄影（HKSV） 可以
  • Thread Border Router 可以
02 · Pairing

四步驟完成第一個 HomeKit 設備

  1. 準備
  2. 掃描設定碼
  3. 設定資訊
  4. 測試
Step 1 · 準備iPhone 連上 Wi-Fi、開啟藍牙。設備通電，確認指示燈亮起。
Step 2 · 掃描設定碼打開家庭 App，按「+」，掃描設備背面的 8 位數 HomeKit 設定碼。
Step 3 · 設定資訊為配件命名（例如「客廳立燈」）、分配房間、加入喜好項目。名字取得好，之後 Siri 才叫得動。
Step 4 · 測試點圖示測試開關，再說「嘿 Siri，打開客廳立燈」，確認語音控制也通。
02 · Automation

情境是手動按一下，自動化是條件到了自己動

情境（Scene）是一組設備狀態的快照，輕觸或一句 Siri 啟動。自動化（Automation）依條件自動執行，完全不需要介入，它才是 HomeKit 真正的大腦。

  1. 時間驅動
  2. 地點驅動
  3. 感測器驅動
  4. 離家自動化
Type 1 · 時間每天日落時，自動開啟戶外燈光。不用記、不用按。
Type 2 · 地點手機回到家附近（GPS），玄關燈亮起、空調啟動。你進門時家已經準備好。
Type 3 · 感測器門窗被意外開啟：推播警報、攝影機錄影、全屋燈光開啟，三件事同時發生。
Type 4 · 離家最後一個人離開家：關閉所有燈光、鎖門、降低空調設定。

03 Chapter 03

網路架構基礎認識

訊號的第三站。穩定的家庭網路是智能家庭的地基，設備掉線多半從這裡查起。

  • 一條線進來，四台設備分工數據機、路由器、交換器、AP。各做一件事。
  • IP 是門牌智能設備建議固定 IP，DHCP 重新分配後設備會「消失」。
  • 2.4 GHz 是智能設備的頻段穿牆遠、速度慢；頻道只選 1、6、11。
03 · Devices

四台設備，各做一件事

  1. 數據機 Modem
  2. 路由器 Router
  3. 交換器 Switch
  4. 無線基地台 AP
  5. 整體
1 · 數據機把 ISP（電信商）的光纖或 ADSL 訊號，轉換成乙太網路訊號。通常由 ISP 提供，不用自己設定。
2 · 路由器家庭網路的核心。負責分配 IP 位址（DHCP）、管理所有設備的流量，通常也提供 Wi-Fi。
3 · 交換器擴充有線網路埠。路由器的埠不夠用時，接交換器增加接口。智能交換器支援 VLAN。Apple TV、HomePod 這類 Home Hub 走有線最穩。
4 · 無線基地台單純提供 Wi-Fi，本身沒有路由功能。大坪數住宅部署多台 AP 延伸訊號覆蓋。智能設備大多掛在這一層的 2.4 GHz。
整體一條線進來，路由器分配、交換器擴埠、AP 撒 Wi-Fi。智能設備在最末端；它掉線，往前一站一站查。
03 · PoE

PoE：網路線同時送資料和電

  1. 沒有 PoE
  2. PoE 交換器
  3. PoE 注入器
Before · 沒有 PoEAP、攝影機除了網路線，還要另外找插座接變壓器。天花板上沒插座，走線就麻煩。
PoE 交換器Power over Ethernet：具備供電能力的交換器，每個埠可輸出 15 W（802.3af）或 30 W（802.3at / PoE+）。大量部署 AP 或攝影機的標準配置。
PoE 注入器單埠供電轉接器，插在現有路由器／交換器與設備之間。只有一兩台 PoE 設備時的低成本方案。

規格要匹配：af（15 W）給輕量設備，at / PoE+（30 W）給高功耗 AP 或帶加熱器的攝影機。線材 Cat5e 以上。常見 PoE 設備：AP、IP 攝影機、智能門鈴、門禁讀卡機、部分 IoT Hub。

03 · IP

IP 位址：每台設備的門牌

  1. IP 位址
  2. 子網路與閘道
  3. DHCP
  4. 靜態 IP 與 DNS
1 · IP 位址網路上每台設備的地址，就像門牌號碼。例如 192.168.1.100。
2 · 子網路與閘道子網路遮罩 255.255.255.0（/24）定義哪些設備在同一條街。閘道（Gateway）是通往外面的出口，通常就是路由器 192.168.1.1。
3 · DHCP路由器自動分配 IP 給新連線的設備。插上就能用，不用手動設定。但租約到期或重開機後，號碼可能換。
4 · 靜態 IP 與 DNS手動指定固定 IP，設備重啟後不會變。智能 Hub、NAS、攝影機建議固定（或在 DHCP 綁定 MAC）。DNS 把網址翻成 IP，例如 Google 的 8.8.8.8。
03 · Wi-Fi

2.4 GHz 走得遠，5 GHz 跑得快

  1. 2.4 GHz
  2. 5 GHz
  3. 頻道 1、6、11
2.4 GHz 穿透力強、距離遠，但速度較慢（理論最高 600 Mbps）、干擾多。智能家庭大多數設備（智能插座、低功耗感應器、Thread Border Router）只支援 2.4 GHz。
5 GHz 速度快、干擾少，但距離短、穿牆差。適合手機、電腦、Apple TV、NAS 這些高頻寬設備。
頻道 1、6、112.4 GHz 有 13 個頻道（台灣），每個佔 20 MHz，但間距只有 5 MHz，相鄰頻道會重疊。只有 1、6、11 彼此間距 25 MHz、完全不重疊。你選頻道 2，會同時被 1 和 3 的網路干擾，等於雙倍。多台 AP 就交錯用這三個。

常見坑：路由器把 2.4 / 5 GHz 合成同一個 SSID（混頻），設備會加不進 HomeKit。分開 SSID，確保設備連到 2.4 GHz。

本章重點

第三章 網路架構基礎認識

  1. 智能設備強烈建議使用靜態 IP（或 DHCP 綁定 MAC），DHCP 重新分配後設備會「消失」
  2. 2.4 GHz 選頻道 1、6、11（非重疊頻道）；多台 AP 交錯使用這三個頻道
  3. PoE 讓網路線同時供電，是部署 AP 和攝影機的標準方案，用 Cat5e 以上線材即可

04 · Protocols

六種協定，一次看一個

每個協定只問兩件事：省不省電？要不要中介設備？

  1. Wi-Fi
  2. Thread
  3. Zigbee
  4. Z-Wave
  5. Bluetooth LE
  6. Matter
Wi-Fi幾乎所有設備都支援、不需額外 Hub、速度快適合攝影機。缺點：耗電大不適合電池設備，設備一多容易壅塞。適合攝影機、冰箱、洗衣機。
Thread極低功耗、基於 IPv6 的新世代 Mesh：設備加入自動形成最佳路徑，加密與身份驗證完善。缺點：支援設備仍在成長，要搭配 Matter 或 Border Router。適合感應器、開關。
Zigbee低功耗、Mesh 自動中繼覆蓋廣、內建加密、市佔率高（最多 65,000 個節點）。缺點：不同廠牌晶片有微小差異未必互通，要橋接 Hub 才能接入 HomeKit。適合燈泡、開關、感應器。
Z-Wave低功耗、用 868 / 908 MHz 避開 2.4 GHz 干擾、穿牆佳、加密良好。缺點：需要協調器（Hub），設備比 Zigbee 少、部分偏貴。適合門鎖、開關、感應器。
Bluetooth LE低功耗、配對簡單不需 Hub、模組便宜。缺點：距離短（約 10 公尺）、多設備易干擾、無法跨房間遠端。適合門鎖、體重計、近距離感應器。
Matter 應用層標準（2022 年推出），跑在 Wi-Fi 或 Thread 之上。跨平台：同一設備不鎖單一平台；開源、隱私、資料不經雲端中轉。缺點：支援仍在擴展，需要支援 Matter 的 Hub 或 Border Router。

04 · Hub vs Border Router

翻譯官，還是橋樑

  1. Hub / Bridge
  2. Border Router
Hub / Bridge · 協定橋接Zigbee、Z-Wave、Bluetooth 設備本身沒有 IP 位址，沒辦法直接跟網路講話。Hub 的工作是把這些「非 IP 協定」翻譯成 IP 訊號，再轉交給 HomeKit。
Border Router · 邊界路由器Thread 設備本身就是 IPv6 設備，有自己的 IP。Border Router 不做翻譯，只負責把 Thread 的 Mesh 網路「接通」到家裡的 Wi-Fi。Apple TV 4K、HomePod 內建這個角色。

一句話記住：Hub 是翻譯官，設備不懂 IP，它幫忙翻譯。Border Router 是橋樑，設備本身懂 IP，它只幫忙接路。

04 · Architecture

從設備到 Home Hub，訊號怎麼上去

  1. 設備
  2. 三種中介
  3. Home Hub
  4. Matter
Layer 1 · 設備牆上的燈、開關、門鎖、插座、攝影機、感應器。每一個都講自己的語言：Zigbee、藍牙、Wi-Fi、Thread。
Layer 2 · 三種中介Zigbee 和藍牙設備經 Hub 翻譯；Wi-Fi 設備直連路由器；Thread 設備經 Border Router 接通。三條路都通往家裡的 IP 網路。
Layer 3 · Home HubHomePod 或 Apple TV 在最上面收所有設備的狀態、發指令、跑自動化，出門時代收遠端指令。
Layer 4 · MatterMatter 橫跨在上面，統一指令格式：同一台設備，不同品牌的 Hub 與 App 都聽得懂，不鎖單一平台。
04 · Matter + Thread + HomeKit

三位一體：HomeKit 的未來

  1. Matter
  2. Thread
  3. HomeKit
Matter · 跨品牌互通標準打破品牌壁壘，所有支援 Matter 的設備順暢溝通。同一設備不再鎖定單一平台。
Thread · 低功耗 Mesh 連線每個 Thread 設備都能當訊號中繼點，形成可自我修復的 Mesh。某設備離線，網路自動找最佳路徑，反應更快、更穩。
HomeKit · 三者合一HomeKit 高標準隱私 ＋ Matter 跨平台互通 ＋ Thread 穩定 Mesh，共同構成現代智能家庭的最佳標準。HomePod、Apple TV 4K（第 2 代後）自動擔任 Thread Border Router，不用另外買設備。
選擇建議

現場怎麼選

  • 一般住宅新裝
    優先選 Matter + Thread 生態設備。未來相容性最好，不鎖單一平台。
  • 預算有限 / 改裝
    選 Zigbee 生態（Aqara、飛利浦 Hue、IKEA Tradfri）。設備選擇多、價格親民。
注意

Zigbee 與 Z-Wave 都需要 Hub（橋接器）才能接入 HomeKit。常見 Hub：Philips Hue Bridge、Samsung SmartThings、Home Assistant。

Thread 也在 2.4 GHz

Thread 用 IEEE 802.15.4，頻道編號 11 到 26（共 16 個，每個 5 MHz 寬），跟 Wi-Fi 的頻道號碼系統完全不同，不可混用。Thread 建議用 15、20、25 或 26，這些恰好落在 Wi-Fi 頻道 1、6、11 的空隙或邊緣，干擾最小。第三章把 Wi-Fi 固定在 1、6、11 之後，Thread 也能在乾淨的頻譜裡跑。

本章重點

第四章 相關通訊協定總覽

  1. Thread 是傳輸層（Mesh 網狀、低功耗、2.4 GHz），Matter 是應用層（統一指令格式），兩者不衝突，常一起使用
  2. Wi-Fi 設備配置最簡單但功耗高；Thread 設備穩定省電，但需要 Border Router（Apple TV / HomePod mini）
  3. Zigbee / Z-Wave 設備需要各自的 Hub 作為翻譯橋，不支援 Matter 的舊設備無法直接加入 HomeKit

05 Chapter 05

接燈與開關的電氣知識

訊號的第五站，也是唯一會碰到 110V 的一站。台灣家用電的基礎數字，先看這四個。

  • 先斷電，再驗電接線前關斷路器、用驗電筆確認無電。這不是建議，是底線。
  • 開關只裝在火線上N 零線直通燈具、繞過開關；開關關了，電箱到開關那段火線仍帶電。
  • 控制器要 L 也要 N零火版靠 N 待機；單火版只靠 L，LED 可能閃，懷疑鬼火先加電容。
05 · Wire colours

五種顏色，各是什麼

  1. 紅：火線 L（電燈）
  2. 黑：火線 L（插座）
  3. 白／灰：中性線 N
  4. 綠：接地線 E
  5. 黃／藍：燈線
紅火線 L，電燈迴路。帶電 110V，需謹慎操作。
黑火線 L，插座迴路。一樣帶電 110V，舊式配線常見。
白／灰中性線 N，也叫零線。是電流的回路，近似 0V，從電箱直通燈具、不經過開關。
綠接地線 E（Earth）。安全保護用，正常情況不通電流。
黃／藍燈線，也叫控制線。開關到燈具的那一段。開關打開時它也帶電，別當它是安全的。
05 · Circuit

一般迴路：電從哪來，從哪回去

  1. 電箱
  2. 火線 L 到開關
  3. 開關
  4. 燈線到燈具
  5. 零線 N 回電箱
  6. 把開關關掉
1 · 電箱家中每一條燈具迴路都從電箱（配電盤）出發。每條迴路有自己的無熔絲開關（NFB）。
2 · 火線 L火線從電箱出來，先進開關。台灣電燈迴路用紅線，帶電 110V。
3 · 開關開關就裝在火線上，只做一件事：把火線接通或斷開。端子 0 進、1 出。
4 · 燈線從開關 1 號端子出來到燈具的那一段叫燈線（黃）。開關打開時它帶電。
5 · 零線 N零線從電箱直接拉到燈具、繞過開關。電流從 L 進、經燈、由 N 回電箱，迴路完整，燈亮。
6 · 開關關掉開關斷開後，燈線不帶電、燈暗。但電箱到開關那段火線仍然帶電。N 完全不受開關控制。

重點觀念：開關只安裝在火線（L）上。這就是為什麼關了開關還是會被電。

05 · Switches

單切開關與雙切開關

  1. 單切：0 進 1 出
  2. 雙切：兩邊都撥上
  3. 撥開關 1
  4. 撥開關 2
單切開關 · Single Pole控制單一燈具。兩個端子：0 接火線 L（進），1 接燈線（出）。台灣標準。
雙切開關 · 3-Way兩個位置控制同一盞燈（樓梯）。每個開關三個端子：0（公共端）、1、3。兩個開關之間用「雙切線 1」和「雙切線 3」互連。兩邊都撥向 1，電流走雙切線 1，燈亮。
撥動開關 1開關 1 的 0 改接到 3。但開關 2 還接在 1，電流沒有路，燈暗。
撥動開關 2開關 2 的 0 也改接到 3。電流改走雙切線 3，迴路又通，燈亮。撥動任一開關都改變 1／3 的通斷組合，這就是樓梯上下各控一燈的原理。
05 · Smart circuit

把控制器串進迴路

  1. 原本的迴路
  2. 換上控制器
  3. 補一條 N
  4. 一顆控多燈
原本一般開關只做火線通斷。一個開關對應一盞燈，沒有遠端、沒有排程。
換上控制器智能開關控制器等於把「開關」換成一顆有晶片的盒子，串入原本的迴路。火線 L 進來、燈線從 L1 出去到燈。但晶片要有電才能待機。
補一條 N所以控制器需要同時接 L 火線與 N 零線，從 L→N 取電，才能一直開著等指令。原本開關盒沒引 N 線的迴路，要補拉 N 線，或改選「免 N 線」型號（下一頁）。
一顆控多燈接好 L 與 N 之後，一顆控制器可以獨立控制 L1、L2 多組燈具，支援 App 遠端、排程、語音。

重要差異：零火版控制器要 L＋N 才能待機。舊線路沒有 N 到開關盒，先重新配線補拉，或選單火版。

05 · No-neutral switch

零火、單火，以及為什麼要加電容

  1. 零火版（需 N 線）
  2. 單火版（免 N 線）
  3. 為什麼 LED 會閃
  4. 並聯一顆電容
零火版開關盒有 L 火線和 N 零線兩條線。控制器從 L→N 直接取電，供電穩定、功能完整、支援所有燈具。適合新裝修或已預留 N 線的盒體。缺點：舊線路要補拉 N。
單火版開關盒只有 L 和燈線、沒有 N。控制器在「關燈」狀態下，靠一股微弱的持功電流（＜1 mA）穿過燈具回 N，為自己的待機電路充電。免重新配線，安裝簡單。
為什麼 LED 會閃LED 燈啟動功率極低。那股微電流會不斷幫 LED 內部電容充電，累積到一定程度就閃一下（微閃），或夜裡隱隱發亮，俗稱鬼火。燈具阻抗太高時，控制器也可能因供電不足而重啟、掉線。
並聯一顆電容在燈具兩端（燈線與 N 之間）並聯一顆電容，也叫單火適配器。它在交流電路裡是一條旁路（Bypass）：關燈時微電流優先走電容、不流進 LED 驅動晶片，閃爍消失；同時給控制器一條低阻抗的穩定迴路。通常裝在燈具或天花板接線盒內。

選購：開關盒有 N 線就選零火版，穩定度高。確定沒有 N 才選單火版，並先確認燈具品牌相容，必要時補電容或換燈。

05 · Safety

活電作業四步驟

這是合理的操作需求，但每一步都不能省。

  1. 確認帶電線
  2. 標記各線
  3. 關閉 NFB
  4. 施工完成才送電
1 · 確認帶電線確認迴路時，通常要在通電狀態下用驗電筆判斷各線角色（L、N、燈線）。非接觸式驗電筆靠近導線，看指示燈亮不亮。驗電筆不需碰線體，切勿用手指感知。
2 · 標記各線確認後立刻用膠帶標記 L、N、燈線各自的功能。避免放下工具後忘記，造成二次混淆。
3 · 關閉 NFB到配電盤關閉對應迴路的無熔絲開關。關閉後再用驗電筆確認無電，才能動手接線。
4 · 施工完成才送電確認線頭包覆、螺絲鎖緊後才恢復供電測試。不要帶電測試接線正確與否。
工具與禁止

必備工具，絕對禁止

  • 非接觸式驗電筆
    不碰線體即可確認帶電狀態
  • 三用電表
    量測電壓、確認 N 線是否到位
  • 絕緣手柄工具
    螺絲起子、尖嘴鉗須有絕緣外皮
  • 絕對禁止
    雙手同時觸碰 L 線與 N 線
  • 在潮濕環境進行電氣作業
  • 用手直接觸碰裸露線頭確認是否帶電
  • 未確認無電就拆接線
本章重點

第五章 接燈與開關的電氣知識

  1. 接線前務必關斷路器並用驗電筆確認無電，這不是建議，是安全底線
  2. 零火版開關需要 L + N 兩條線；單火版只需要 L，但 LED 燈可能閃爍，懷疑鬼火先試加電容
  3. 雙切開關端子是 0、1、3（台灣標準），0 接火線進，1 與 3 是聯動線
Appendix · Troubleshooting

出問題了，沿著那條路查

章節的順序就是排查的順序：從手機那一端往牆裡查。

  1. 設備加不進 HomeKit
  2. 設備頻繁掉線
  3. 遠端無法控制
  4. Thread 設備訊號差

站 3 · 路由器／Wi-Fi 頻段設備只支援 2.4 GHz，但路由器把 2.4 / 5 GHz 混成同一個 SSID。分開 SSID，確保設備連到 2.4 GHz。第三章。
