認識智能家庭

智能家庭（Smart Home）透過網路連接各種家用設備，讓使用者能用手機、語音或自動化情境來控制照明、空調、安全、娛樂等系統。

常見智能家庭設備分類

照明系統

智能燈泡、智能開關、調光器、燈帶。最常見的入門設備，效益最直接。

安全監控

智能門鎖、門磁感應器、動作感應器、攝影機、煙霧偵測器。

環境控制

智能溫控器、空調控制、窗簾/捲簾馬達、空氣品質感應器。

能源管理

智能插座（含電量監控）、電費計算、太陽能系統整合。

三大生態系統比較

Apple HomeKit

嚴格認證、隱私保護強、操作最流暢，但相容配件較少且售價偏高。

Google Home

Android 整合佳、AI 語音能力強，跨品牌支援廣泛，隱私爭議較多。

Amazon Alexa

相容設備最多、技能生態豐富，但在台灣支援度有限。

Matter（跨平台）

2022 年推出的統一標準，同一設備可同時接受 HomeKit / Google / Alexa 控制。

重點觀念
智能家庭的核心是「互聯」與「自動化」。單一設備不是智能家庭，設備彼此能感知、聯動才是真正的智能。

相關通訊協定總覽

不同設備使用不同的無線/有線協定溝通。了解各協定的特性，才能在安裝時做出正確的設備選擇。

協定 頻段 拓撲 耗電 需要 Hub 適合設備 備註
Wi-Fi 2.4 / 5 GHz Star 高 不需要 攝影機、冰箱、洗衣機 直接連路由器，設定最簡單
Zigbee 2.4 GHz Mesh 低 需要 燈泡、開關、感應器 最多 65000 個節點，市佔率高
Z-Wave 868/908 MHz Mesh 低 需要 門鎖、開關、感應器 不受 2.4GHz 干擾，穿牆效果佳
Thread 2.4 GHz Mesh 極低 Border Router 感應器、開關、Matter 設備 基於 IPv6，Matter 的底層傳輸協定之一
Matter Wi-Fi / Thread Star/Mesh 依底層 不需要 新世代跨平台設備 應用層標準，跑在 Wi-Fi 或 Thread 上
Bluetooth LE 2.4 GHz Star 低 不需要 門鎖、體重計、感應器 距離短（約 10m），適合近距離設備
KNX 有線（雙絞線） Bus N/A 需要 商業建築、豪宅 工業級可靠性，工程複雜，造價高
RS-485 有線 Bus N/A 需要 大樓門禁、中央空調 工業通訊標準，Modbus 協定常用此物理層

協定選擇建議

一般住宅新裝

優先選 Matter + Thread 生態設備。未來相容性最好，不鎖單一平台。

預算有限 / 改裝

選 Zigbee 生態（飛利浦 Hue、IKEA Tradfri）。設備選擇多、價格親民。

商業 / 豪宅

考慮 KNX 有線系統。穩定度最高，但需要專業工程師配線。

注意
Zigbee 與 Z-Wave 都需要 Hub（橋接器）才能接入 HomeKit 或 Google Home。常見 Hub：Philips Hue Bridge、Samsung SmartThings、Home Assistant。

Apple HomeKit 深入了解

HomeKit 是 Apple 於 2014 年推出的智能家庭框架，透過「家庭」App 統一管理所有認證設備，並以隱私保護著稱。

HomeKit 架構組成

Home Hub（家庭中樞）

Apple TV 4K、HomePod、HomePod mini。讓你在外也能遠端存取設備，並執行自動化。

至少需要一台才能啟用遠端控制與自動化。

HomeKit 配件

通過 MFi（Made for iPhone）認證的設備。認證確保加密通訊與資料安全，所有資料不經 Apple 伺服器，直接點對點傳輸。

家庭 App

iOS / iPadOS / macOS 內建。管理設備、建立自動化、共享家庭成員存取權限。

Siri 語音控制

「嘿 Siri，關掉客廳的燈」、「把溫度設定到 25 度」。透過 HomePod 可做到全屋語音控制。

HomeKit 支援的服務類型

類別 包含設備 常用指令範例
照明 燈泡、燈帶、調光器、開關 「打開臥室燈」、「把亮度調到 50%」、「切換成暖白色」
氣候 溫控器、冷氣、暖氣、空氣清淨機 「把客廳溫度設為 24 度」
安全 門鎖、攝影機、門磁、動作感應 「鎖上前門」、「查看門口攝影機」
窗簾/遮陽 電動窗簾、百葉窗、捲簾 「把臥室窗簾打開一半」
插座/開關 智能插座、智能排插 「關掉咖啡機」
感應器 溫濕度、空氣品質、漏水偵測 自動化觸發條件

情境（Scene）與自動化（Automation）

情境（Scene）

手動觸發一組設備狀態。

例如「電影模式」= 燈光調暗至 20%、窗簾關閉、電視開啟。

自動化（Automation）

依條件自動執行。

例如「早上 7:00 打開臥室燈」、「我回家時開冷氣」、「最後一個人離家後關閉所有燈」。

Matter 與 HomeKit 的關係

重要
Matter 設備可直接加入 HomeKit，無需任何 Hub 或橋接器。從 iOS 16 起，Home Hub 同時可作為 Matter Border Router，讓 Thread 設備透過它連接 HomeKit。這是未來智能家庭的主流方向。

HomeKit 安裝注意事項

  • 確認設備包裝上有 HomeKit 標誌（或 Works with Apple Home）
  • 家庭 App 掃描設備背面或說明書的 8 位數配對碼（HAP code）
  • 設備需在同一 Wi-Fi 或透過 Hub 連線
  • 每個家庭最多可加 150 個配件，16 個房間，100 個情境
  • 家庭成員共享需邀請（需有 Apple ID），可設定不同權限等級

接燈與開關的電氣知識

安全警告
進行任何電氣作業前，必須先至配電盤關閉對應迴路的無熔絲開關（NFB），並用驗電筆確認無電後再施工。切勿帶電作業。

三條電線認識

火線 L（Live） ─── 黑色（舊式）或紅色 ──→ 帶電，電壓 110V 中性線 N（Neutral） ─── 白色 ──→ 回路，近似 0V 接地線 E（Earth） ─── 綠色或裸銅線 ──→ 安全保護，不通電流 配電盤 NFB │ ├─── L（黑） ──→ 開關 ──→ 燈具 │ └─── N（白） ──────────→ 燈具（直通）
重要差異
傳統開關只切斷火線，沒有引中性線到開關盒。智能開關需要中性線（N）維持待機電源，因此安裝前必須先確認開關盒內是否有 N 線。如果沒有，需要選擇「無需中性線」型號，或請水電師傅重新配線。

開關接線類型

類型 線數 用途 智能開關相容性
單切開關
Single Pole		 2 條（L、N）或 2 條（L-in、L-out） 一個位置控制一盞燈 需確認是否有 N 線
雙切開關
3-Way		 3 條（L、兩條 Traveler） 兩個位置都能控制同一盞燈（如樓梯） 需成對更換，較複雜
調光開關
Dimmer		 2～3 條 控制亮度 必須確認燈具支援調光

LED 燈與調光器相容性

LED 不一定可調光

LED 燈泡包裝上若有「可調光」（Dimmable）標示才能搭配調光器。一般 LED 硬接調光器可能閃爍或損壞。

前沿 vs 後沿調光

LED 建議使用後沿（Trailing Edge）調光器，效果較平順。前沿（Leading Edge）適合鎢絲燈，用於 LED 易有閃爍問題。

最低負載限制

調光器有最低負載要求（如 40W）。若 LED 燈瓦數太低，可能無法正常運作，需選購支援低負載的調光器。

常用工具

  • 驗電筆（非接觸式）：在不拆線的情況下確認是否帶電
  • 三用電表：量測電壓、電流、電阻
  • 絕緣膠帶：包覆裸露線頭
  • 壓線帽 / Wire Connector：連接多條電線
  • 一字 / 十字螺絲起子（含絕緣手柄）
新人建議
第一次安裝智能開關時，先從「有確認 N 線、單切開關控制一般 LED 燈」的情況開始練習，是最安全、最容易成功的組合。

網路架構基礎認識

穩定的家庭網路是智能家庭的基礎。了解基本的網路架構，才能有效排除設備掉線等問題。

基本網路設備

數據機（Modem）

將 ISP（電信商）提供的訊號（光纖/ADSL）轉換為乙太網路訊號。通常由 ISP 提供，不需自行設定。

路由器（Router）

負責分配 IP 位址（DHCP）、管理所有設備的網路流量。是家庭網路的核心，也提供 Wi-Fi 功能。

交換器（Switch）

擴充有線網路埠。當路由器的有線埠不夠用時，透過交換器增加接口。智能交換器支援 VLAN 設定。

無線基地台（AP）

單純提供 Wi-Fi，本身沒有路由功能。大坪數住宅可部署多台 AP 延伸訊號覆蓋範圍。

IP 位址基礎

名詞 說明 範例
IP 位址 網路上每台設備的地址，就像門牌號碼 192.168.1.100
子網路遮罩 定義哪些設備在同一個網段內 255.255.255.0 (/24)
閘道（Gateway） 通往外部網路的出口，通常是路由器的 IP 192.168.1.1
DHCP 路由器自動分配 IP 給新連線設備 設備插上就能用，無需手動設定
靜態 IP 手動指定固定 IP，設備重啟後不會改變 智能 Hub、NAS、攝影機建議使用
DNS 將網址轉換為 IP（域名解析服務） 8.8.8.8（Google DNS）

Wi-Fi 頻段選擇

2.4 GHz

穿透力強、距離遠，但速度較慢（理論最高 600Mbps），干擾多。

智能家庭大多數設備（Zigbee 橋、智能插座、低功耗感應器）只支援 2.4GHz。

5 GHz

速度快、干擾少，但距離短、穿牆差。

適合手機、電腦、Apple TV、NAS 等高頻寬設備。

IoT VLAN 隔離（重要安全概念）

安全建議
智能家庭設備（尤其是便宜的中國廠牌）安全性參差不齊，建議將 IoT 設備放在獨立的 VLAN，與主要設備（電腦、手機）網段隔離，防止 IoT 設備被入侵後波及主網路。
VLAN 主網路（VLAN 1）

電腦、手機、NAS、Apple TV（Home Hub）。最高安全等級，可訪問所有其他 VLAN。

VLAN IoT（VLAN 20）

智能燈、插座、感應器、空調控制器。可訪問 Internet，但隔離於主網路。

VLAN 攝影機（VLAN 30）

監控攝影機、門鈴。最高隔離，禁止訪問 Internet，只允許錄影到本地 NVR。

Mesh Wi-Fi 系統

傳統的 Wi-Fi 延伸器（Repeater）會降低一半頻寬，現代 Mesh 系統透過多個節點（Node）智慧切換，提供無縫漫遊體驗。

ISP 數據機
光纖入戶
Mesh 主節點
Router + AP（如 UniFi Dream Machine）
Mesh 子節點
純 AP（有線回傳最佳）
IoT 設備
自動連最近節點
新人建議
有線回傳（Wired Backhaul）= 最佳效能。若條件允許，Mesh 子節點應透過網路線連回主節點，而非無線回傳。這能讓每個節點都有完整的頻寬給客戶端設備。

常見網路問題排查

問題 可能原因 排查步驟
設備無法加入 HomeKit 設備只支援 2.4GHz，但路由器 SSID 混頻 分開 2.4/5GHz SSID，確保設備連到 2.4GHz
設備頻繁掉線 Wi-Fi 干擾、IP 衝突、DHCP 租約問題 改用靜態 IP，或在 DHCP 中固定設備 IP
遠端無法控制 Home Hub 離線或網路問題 確認 Apple TV / HomePod 是否在線，重啟 Home Hub
Zigbee 設備信號差 Zigbee（2.4GHz）與 Wi-Fi 頻道衝突 將 Wi-Fi 設定在 1、6 或 11 頻道，避免與 Zigbee 重疊
