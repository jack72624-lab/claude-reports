區塊說明

  1. 1標題 / 品牌：App 名＋作者署名。右側「分享」為建議新增。
  2. 2儀式紀錄卡：日期（原生 date picker，預設今天）＋地點輸入＋清除。＋建議多一個「燒給誰」短輸入，讓出氣有對象、截圖更有梗。
  3. 3烏龜陣：一片待燒的烏龜。原版固定一片；＋建議加「已燒計數」與「加龜」補貨。
  4. 4火焰區：核心互動。中央火坑是拖放目標，烏龜拖入→燃燒動畫→消失。火焰持續竄動氛圍。
  5. 5背景控制：上傳圖／選色／移除，自訂底圖（沿用原版）。

核心互動流程

  1. 進站 → 自動帶今天日期、地點臺灣
  2. （選用）輸入「燒給誰／燒什麼」
  3. 按住烏龜 → 拖進火坑（或點烏龜自動飛入）
  4. 火坑放大 + 燃燒動畫 + 輕震/音效 → 該烏龜消失、計數 +1
  5. 燒完可「再加龜」繼續，或「截圖分享」炫耀戰果
