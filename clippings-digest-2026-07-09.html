這批怎麼看

兩篇講同一件事的兩面。iZotope 那篇是觀念與研究：老規矩「低頻一律 mono」是哪來的、為什麼現代頂尖工程師已經不這樣做、以及該怎麼改。BassLane Pro 那篇是一顆專門實作這個現代做法的 plugin——把低頻做寬做立體、但不破壞 mono 相容。先讀第一篇建立心智模型，第二篇就是「拿什麼工具落地」。

先講兩個一直出現的詞：side channel（側聲道）＝把左右聲道拆成「中間共通的（mid）」和「左右差異的（side）」時，side 就是立體聲寬度的來源；side 越多、聲音越寬。mono 低頻＝把低頻的 side 拿掉、只剩正中央，低頻就完全不寬。整篇的攻防都在「低頻的 side 要留多少」。

Clip 1 · 觀念＋研究

低頻到底該 mono 還是保留立體聲？

iZotope · YouTube 原片（約 16 分）

重點知識

「低頻要 mono」這規矩哪來的

源頭是黑膠母帶：黑膠靠唱針在溝槽裡左右擺動來記錄立體聲，低頻的 side 能量太大會讓唱針跳針、刻不進去，所以要把低頻壓成 mono。第二個推力是PA 音響（現場大喇叭）的超低音喇叭（sub）通常接成 mono，於是「低頻 mono 聽起來更緊、更有力、更一致」變成通則。做法是在 side 聲道掛一個 high-pass filter（有時叫 elliptical filter），把低頻的 side 內容整個切掉——影片把這種一刀切叫做 hard mono（硬 mono）。

硬 mono 的 5 個代價

代價發生什麼事
1. 峰值反而變高很反直覺：把 side 內容濾掉，波形峰值（peak）反而升高。影片 demo 一首餘裕只留 0.2 dB 的母帶，一掛 side 高通就爆出 1.2 / 1 dB 的 over（超過 0 dBFS 破表）。
2. 相位抹糊用非線性相位的 side 濾波器，會在「相位一致最重要」的低頻區把 mid 和 side 的相位關係抹糊。
3. 音量流失side 也帶著能量，砍掉 side＝整體低頻音量會掉一截。
4. 音色改變只存在於 side 的內容叫反相內容；砍掉它不只是砍音量，是砍掉細節——音色會變。
5. 失去包覆感低頻其實有一種可感知的空間感／包覆感，Harman 聲學家 Todd Welti 給它取名 basiousness。硬 mono 會把它整個抽掉，聽起來變得乾扁無趣。

研究怎麼說：低頻其實有寬度、而且聽眾偏好它

  • 過去以為「低頻沒有方向感、沒有寬度」，這已被證明是錯的。人耳其實能定位、也能感知低頻的寬度。
  • David Griesinger 的論文描述了低頻空間感的生理機制；重點是——立體聲低頻不只是「能聽出方向」，更是一種「空間、維度、沉浸」的感覺（就是 basiousness）。
  • 一篇 AES（音訊工程學會）論文做了聽感偏好測試：聽眾明顯偏好有寬度、有空間感的低頻，勝過完全沒處理、也勝過其他不含低頻空間效果的版本。

真實世界驗證：頂尖歌根本沒在硬 mono

影片用 iZotope RX 音訊編輯器的 Mid/Side 頻譜去分析幾首大歌（做法附在下面），結論是這些歌的低頻 side 內容都很豐富、一路延伸到 30 Hz，完全不是硬 mono：

  • Skrillex & Fred again.. 〈Rumble〉（2024 葛萊美最佳電子舞曲、Luca Pretolesi 母帶）
  • Chase & Status 〈Baddadan〉（近年最具代表性的 drum & bass 神曲之一）
  • Mefjus / Camo & Krooked 〈You〉

連 David Guetta 的工程師 Tim Rescinski 都說：「目標不是把立體聲場壓平，而是控制它。寬度該來自好的編曲與音色設計，不是只靠後製；除非有技術問題，我會避免在母帶上做硬立體聲切除。」

現代做法：right-sizing（把寬度調到剛好），不是砍掉

  • 做法 A（簡單）：別用 high-pass 一刀切，改成 low shelf——把 side 的低頻整段緩緩壓低，控制它的量而不是消滅它。
  • 做法 B（進階，用 Ozone Imager）：分 3 個頻段（80 / 150 / 2k Hz），逐段調寬度。搭配 Ozone 的 Recover Sides 功能，把被縮窄時損失的反相細節找回來、加回中央——這樣既控制了寬度、又不流失細節。
自己分析的做法（RX）：開 RX 音訊編輯器 → Mixing 模組 → 選 MS encoder/decoder preset → Render → View 選單把 channel mode 改成 Mid/Side → 打開 spectrum：mid 是淺灰、side 是藍色，是整首平均。就能一眼看到自己各頻段的 side 有多少。

你能學能用的（混音）
  • 停掉反射動作：別再無腦把 120 Hz 以下一律硬 mono。除非要壓黑膠，硬 mono 對現代作品太重手——尤其現在多數人用耳機、全立體聲系統聽。
  • 先量再改：用 RX 的 Mid/Side 頻譜看自己歌裡低頻 side 有多少，再決定要不要動、動多少。
  • 改用 shelf 或多頻段 imager「調到剛好」，保留一點 basiousness；動完回頭看 true peak（記得那個反直覺的峰值上升）。
  • 監聽陷阱：如果你只有一顆 sub，你的低頻在監聽端早就被強制 mono 了——你根本聽不到自己失去了什麼。要判斷低頻寬度，需要全頻段立體聲監聽或耳機。
Clip 2 · 落地工具

BassLane Pro：把低頻做成 3D、又不破壞 mono

Dom Sigalas（Tone Projects 出品）· YouTube 原片（約 18 分）

重點知識

它解的正是第一篇的痛點：怎麼把低頻做得又寬又厚（3D）、卻不損失 mono 相容（在夜店、壓黑膠時 mono 相容很關鍵）。跟 iZotope 的差別是——iZotope 是「馴服你原本就有的 side」，BassLane Pro 是主動生出新的寬度。

核心原理（跟直覺相反的一招）

拿一個訊號（可選 mid / stereo / side），產生諧波（harmonics），然後把這些諧波丟到 side 聲道。所以就算你的低頻本來是純 mono，它也能：(1) 加諧波讓 bass 更厚更豐富、(2) 把這些諧波鋪在立體聲場裡讓 bass 變寬——而且因為原始的 sub 低頻仍是 mono，mono 相容不破。Dom 的形容是「低頻像在環抱你的耳朵」。

主要控制項

控制作用
Mono-below 頻率設一個界線（如 90 Hz），以下全部保持 mono——地基先鎖死。
諧波來源＋種類諧波可從 mid / stereo / side 生成；種類有二次、三次諧波、even / odd / crunchy（偶次較柔、奇次較亮、crunchy 較粗），音色各不同。
Mid–Side 旋鈕把諧波從 mid 往 side 鋪。全轉到 side 時，這些諧波在「summed to mono」會消失（plugin 會用紅色警告你），因為它們是純反相的。
內建相關性表自帶分析表看寬度與相位；影片還用 Cubase 的 multi-correlation meter 交叉驗證：bass 很寬、但低頻仍然同相、沒問題。
Sub filter / Boost可對 side 做過濾去掉低頻髒東西；Boost 是共振濾波器，可以調到跟你的大鼓（kick）同頻，讓低頻更貼。
Dynamics 段對選定頻段做壓縮或擴張——諧波太動態就壓平、或反過來擴張出更多活力。
Mono recovery 段把處理過程中「因反相被抵銷」而流失的訊號救回來（如只在左聲道的 tom）。最進階、多數時候用不到。（＝Ozone 的 Recover Sides 對應功能）
Band-pass 濾波不只低頻——切成帶通就能對中頻做寬、讓鼓組更立體。

母帶情境的用法（Dom 建議）

母帶很嚴謹、不能出錯，他會：先掛一個 12 或 18 dB 斜率的 low-pass，把「要完全 mono 的低頻界線」設好（如 170 Hz）→ 寬度轉到底 → 這條線以下就完全 mono → 再開始從想要的來源（mid/stereo/side）注入諧波做寬。他反覆強調：這 plugin 很深，一定要讀說明書。也會有功能較少的免費版。

你能學能用的（混音）
  • 它就是第一篇「現代做法」的專用武器：iZotope 教你別砍 side、要 right-size 並 recover sides；BassLane Pro 直接幫你生出可控、可回收的低頻寬度，還鎖住 mono 相容。
  • 跟你已建檔的 Uni-L 同廠牌（Tone Projects）——這家 plugin 的共通調性是「把黑箱拆到你能理解、每個動作都有表可看」。
  • 可複用流程：設 mono-below 界線 → 從 mid 生諧波 → 盯相關性表確認同相 → 用 Dynamics 壓平過動態的諧波 →（可選）Boost 調到 kick 同頻。
  • 先量再加：跟第一篇一致——先看你缺不缺寬度，別為了 3D 而 3D；overuse 會讓低頻糊掉。
