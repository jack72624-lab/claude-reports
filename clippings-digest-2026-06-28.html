1情感化設計：讓 app 有生命感

Tim Gabe · The Secret Behind Weirdly Addictive Apps · Duolingo / Phantom / Revolut 案例

一句話：人人都做得出功能的時代，「有用」已經不夠——長期護城河是「打開 app 時的感覺」。靠微互動、慶祝小勝、拋光把產品變得有生命感，三個案例都是設計直接帶動商業數字。
重點知識（三個機制）
  • 微互動即時情感回饋：重複行為（打卡/日誌/habit logging）每完成一次，別只給綠勾，給 bounce / glow / sparkle，讓人覺得被鼓勵、被回應。底盤是 Don Norman《Emotional Design》的情感回饋迴路。
  • 慶祝小勝 + 進度感：用動畫呈現 streak、等級、完成數，給「正在累積、正在建造」的感覺，強化回訪。
  • 拋光建立信任（polish = trust）：金融 / crypto / 健康這類高風險領域，把 motion、transition、視覺細節當核心功能不是裝飾，每個微互動都是 trust signal——而「信任直接影響使用者願意花多少」。
案例數字
  • Duolingo：2022 上全角色動畫，兩年 DAU 14.2M → 34M、付費訂閱翻倍。CEO 公開把 delightful experience 當差異化主因。
  • Phantom（crypto 錢包）：2023 動畫化幽靈吉祥物、建錢包加俏皮動畫，把「crypto 很可怕」變親切 → 美國 App Store 工具類第二，贏 WhatsApp / IG。
  • Revolut：tactile charts（拖手指、圖表發光）、卡片 3D 翻轉打光、細膩 onboarding 動畫，整體 premium，在 fintech 直接換成營收。

2MLX 本機模型服務：Mac 上跑 agentic AI

Apple WWDC26 Session 232 · MLX team · 不上雲、無 API key、零用量成本

一句話：在 Mac 上完全本機跑 agentic loop。核心是 MLX-LM Server 提供一個 OpenAI 相容的本機 endpoint，任何 agent（OpenCode / Xcode / 腳本）把 baseURL 指過去就能用——跟「GLM 路由」是同一招，差別是 local + 隱私 + 免費 vs 便宜雲端。
重點知識
  • 四層 stack：MLX（Apple Silicon 陣列框架 · Metal）→ MLX-LM（載入/量化/微調）→ MLX-LM Server（OpenAI 相容 HTTP，支援 tool calling）→ Agent 層。Ollama / LM Studio / vLLM 都已建在 MLX 上。
  • 三步上線：pip install mlx-lm → mlx_lm.server --model ... → 把 agent 的 baseURL 指到 http://127.0.0.1:8080/v1。agent 不知道也不在乎模型是在本機還是雲端。
  • M5 Neural Accelerators：矩陣乘法比 M4 快 4 倍 → prompt processing 約 4 倍（agentic loop 大多 token 是讀進來的 context，這塊很有感）。不用改 code，MLX 自動選 kernel。
  • Continuous batching：多 subagent 同時打 server 時動態併批、新請求中途可加入，不用排隊。
  • 分散式推論：模型太大塞不下單機（DeepSeek 1.6T，權重 >800GB）時，用 mlx.launch + hostfile 把模型 shard 到多台 Mac；macOS 26.2 起支援 Thunderbolt RDMA，4 節點最高 3 倍。

圖解二：四層 stack——你只需要把 agent 指到第二層的本機 endpoint
你能用在哪
  • MCP 直連 POC：你想做「獨立腳本直連 + 模型可切 Claude/Ollama」，MLX 就是那個本機引擎選項（Ollama 本身建在 MLX 上）。要切本機就把 base_url 改成 localhost。
  • 跟 GLM 路由同一招：你已經會「把 agent 指到相容 endpoint」省成本（z.ai），這篇是它的「本機免費 + 隱私」版本，補上離線 / 敏感資料場景。
  • config 可直接抄：OpenCode 的 provider 片段已存進正本，要接時複製改 baseURL 即可。
決定前要知道的限制
  • 本機小模型（Qwen 4B 級）能力遠不如 Opus，實用場景窄：隱私 / 離線 / 零成本 / 簡單 tool-calling，不會取代現在的 Claude Code 工作流。
  • M5 的 4 倍加速是 M5 限定；分散式要多台 Mac + Thunderbolt，個人單機用不到。
