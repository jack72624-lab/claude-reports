1手機號碼為主

手機號碼是天然去重主鍵，且通訊錄本來就存了。不靠 LINE 拿好友名單（LINE 不開放 API），只當登入/分享邀請通道。

2OTP 支援自動填入

iOS WebOTP API 讓系統自動帶入簡訊驗證碼，降低 ~30% 流失。

3Compare-and-forget（PDPA）

通訊錄比對後立即刪除非用戶資料，不落地儲存。文案明確告知目的，MVP 前找律師確認合規。

4⚠️ Onboarding 完成條件

必須加到至少 5 位已在 App 上的朋友才算「啟用完成」，否則整個核心迴圈是空的。Zenly 模式。

5沒有在 App 的朋友

顯示「傳邀請」入口，走 LINE 分享連結，繞開代非用戶同意的問題。

1一顆鈕再展開

主畫面只有 Avatar + I'm Free。按下去才問 Now/Plan，符合「先表達衝動再細化」的心理順序。Phase 0 先只有 Plan。

2Vibe 必選，但零成本

一排 emoji 一鍵選，沒有「不選不讓過」的壓迫感——但每則廣播都帶意圖，避免看板淪為空氣廣播。

3限時自動結束

截止點到了安靜過期，不倒數催促，不跳「還沒有人」。到點自動熄燈，零愧疚。

4⚠️ 永不顯示「0 人回應」

等待畫面只顯示正向語氣（「你的朋友正在看」），至少有 1 人加入後才顯示參與者數量。這是生死題。

5可見範圍可調

不自動擴大，但發起人在等待畫面可自行調整「給誰看」，主導權完全在發起人手上。

1推播只給摯友

發起人設為摯友的朋友才會收到「叮」（震動推播）。普通朋友只會在綠燈看板被動看到，不被打擾。

2社會擔保要顯眼

「透過誰邀請你 + 你們有幾位共同朋友」是最重要的信任鉤子，要放在最顯眼的位置。這就是 LINE 做不到的差異化。

3加入前只給必要資訊

1草皮 + Avatar 是招牌氣質

每當有人加入，他的 Avatar 走進草皮——「活動正在長大」的即時正向回饋。Phase 0 先用簡單頭像，動畫留之後。

2完全不做已讀

訊息旁只顯示時間，沒有「X 人已讀」。這不只是技術省略，而是品牌承諾——對外說清楚「揪起來沒有已讀壓力」。

3加入訊息一律正向

「🐬 海豚子 也有空了！」而非「XX 已加入群組」，用語氣強化「活動正在長大」的感覺。

4Online presence 取代已讀

「N 人在線」的 presence bar 取代逐則已讀，給發起人輕量的「有人看到了」感，同時不產生壓力。

5⚠️ 不做通用 1 對 1 私訊

新朋友的互動先在群體空間發生。1 對 1 私訊要互加好友後才解鎖。在台灣永遠贏不了 LINE，不用試。

1⚠️ 這個畫面是北極星的命脈

沒有見面確認，就無法量測「約成見面轉換率」——唯一重要的指標。Phase 0 第一天就要有，哪怕只是一個問句。

2完全 opt-in，不強迫回答

跳過也沒關係。不顯示「幾人沒回答」。沒有已讀。這個問句要讓人覺得是對話，不是數據收集。

3沒去成：零失敗標記

永遠不出現「揪失敗」「沒人來」等字眼。沒去成就是沒去成，溫暖收尾，下次繼續揪。

4見面成功：升級群組

「要不要存成常用群組」是有機長大的關鍵——讓一場成功的活動升級為固定團，且新朋友需本人同意才加入。

5再揪一次

「一鍵重發」直接降低下次發起的摩擦——發起人是稀缺資源，讓重複揪的成本趨近於零。
