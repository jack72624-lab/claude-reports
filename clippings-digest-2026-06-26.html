1Claude Tag：Slack 裡的常駐 AI 同事

把 Claude 從「對話框」變成有帳號、有權限、跟著頻道累積脈絡的團隊成員

一句話：不是在 Slack 多開一個問答機器人，而是讓 Claude 當一個常駐、主動、能讀全頻道脈絡又能實際動手（寫 PR / 跑分析 / 處理 incident）的同事——Anthropic 內部 65% 產品代碼已來自它。
重點知識
  • 定義（官方）：Claude Tag 是「Claude Code 的進化，更主動、為整個團隊設計」。@ 一下 Claude，它把任務拆階段、用手上的工具做完、在 thread 回覆成果。
  • 一頻道一個共享 Claude：隊友能接著你的進度繼續；它跟著頻道累積脈絡，不用每次從頭交代。開 ambient 模式它會主動跟進冷掉的 thread、跨頻道標出相關的事。
  • 它真的會動手：寫/合 PR、跑資料分析、處理 incident、bug triage、盯 metrics。一個實測者說「丟一個 codebase 給它，它讀完列出 10 個最該修的問題、排序、改好、開 review，全在 Slack 裡」。
  • 65% 數據：Anthropic 產品團隊現在 65% 的代碼來自內部版的 Claude Tag（兩篇來源一致）。
  • 權限按頻道隔離：法務群的分身能看合約機密但碰不到研發代碼，反之亦然，越權直接拒絕（因為那個分身根本沒鑰匙）；所有操作記在它自己帳號日誌。不同頻道的 Claude＝不同工具/權限/脈絡。
  • Karpathy：LLM 介面第三次重設計：①你去的網站 → ②你下載的 app → ③自帶、常駐、非同步、有組織級工具與脈絡、跟人類團隊並肩工作的實體。
  • 設定撇步（Tariq）：用 pin message + 指令當該頻道的「CLAUDE.md」（會進記憶）；另開個人頻道（如 你的名字-Claude）放自己的工作、把訊息轉進去交辦。

完整面：它的挑戰（別只看炒作）
  • 「many Claudes 很混亂」：Slack 裡沒有單一「我的 Claude」，每頻道一個、admin 設定、都不屬於你。
  • 人的層面摩擦（Gail Weener）：你一 tag，它就讀所有人訊息，容易變成「你帶進大家工作區的監控裝置」；做得好被酸「外包思考」、做不好被酸「早說了」，兩面不討好。
  • 設定比看起來複雜：access / 工具設定一堆眉角，Anthropic 另出了 agent identity 與 permissions 最佳實踐文。
  • 鎖定疑慮（尤其 Fable 事件後）：有人寧可自建 Slack agent（如 Hugging Face）也不想綁單一封閉供應商。
你能學能用的
  • 你早就手刻過個人版：你的 Telegram bridge（@YUclaudeagent_bot）就是「把 Claude 放進日常通訊軟體、常駐、用大白話交辦」——Claude Tag 是這套的官方產品化＋多人版。可拿官方怎麼解 resume 記憶/閒置/身分，回頭對照你 bridge 的設計。
  • prompting → delegation 正是你 plan-pipeline 和分視窗平行工作法的核心：給目標、不給逐步指令。這篇給了這個轉變的完整論述可引用。
  • 「pin message 當頻道 CLAUDE.md」＝你熟的 CLAUDE.md 機制搬到群聊，概念可直接遷移到任何你接的 agent。

2Claude Design 2.0：設計與寫碼合流

從「只能看不能改的半成品」變成可算 ROI 的生產工具，把設計→代碼→活資料串成閉環

一句話：關鍵不是它更會生圖，而是把 Design 跟 Code 的帳單/算力打通、塞進頁內編輯器、用 Design Sync 鎖品牌規範，再一路接到 Supabase 變成活的數據面板——設計和開發的邊界被打掉。
重點知識
  • 帳單打通：Claude Design 與 Claude Code 額度全面整合，共用 5 小時會話 + 週額度池。對企業＝設計部與開發部不用各買一套 AI，一套帳單搞定，從玩具變成可算投報率的工具。
  • 一鍵匯出 PowerPoint：內建幻燈片工作流，產出帶講者備註、可全螢幕、多層級的檔，一鍵匯出原生 PPT 格式——直接對標微軟 Office。也能生 app 原型/線框圖/文件/影片動畫。
  • 頁內全功能編輯器：點畫布上任何元素，就能像傳統設計軟體改文字/字級/字體/粗斜；還有圖層視圖（像 Figma）。
  • 新交互鐵律：模型做 0→1 的框架構建，人類滑鼠做 1→100 的微調，不再為了一個像素的偏差反覆燒 token。
  • MCP 連接器：把第三方工具掛進設計流程。例：生商業簡報時直接說一句「叫某圖像模型生一張封面配圖」，系統跨平台調資源貼進頁面。
  • Design Sync：在寫碼端設好品牌規範（字體/主色/風格），一個指令把整套「視覺基因」打包傳到設計端，之後每個按鈕/儀表板都忠實遵循品牌手冊，消滅產出跟品牌調性脫節。
  • 標記工具：在圖上圈出不滿意處留評論 → 左側自動拉出修改清單逐項改。

你能學能用的
  • 帳單打通 + 一鍵 PPT：對你的簡報系統（open-slide 工作區）和威琳對外提案是直接生產力，少掉「套殼網站生大綱 → 抓圖 → 回本地排版」整條。
  • Design Sync ≈ 你的 DESIGN.md 品牌庫機制：你本來就在玩 awesome-design-md / ckm-design；威琳要做品牌一致的報價單/官網時，「規範→一致輸出」就是這個機制的官方版。
  • 0→1 模型、1→100 人類＝你「線框圖優先」工作流的官方背書，可拿來定義你接案/自用的標準分工。
  • 設計→Supabase 閉環：你的威琳庫存（Next+Supabase）、Routine、收入計算機都是這套疊；值得看它怎麼把畫面直接接活資料、省掉切圖標註交接。
