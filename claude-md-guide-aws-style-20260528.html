為什麼需要優化？

每次對話開始，Claude 都會把 CLAUDE.md 完整載入記憶體，就像開電腦時桌面上的東西。放越多，找規則越慢、越容易混亂。

CLAUDE.md
工作桌面

每次開啟 Claude，這些內容立刻出現在眼前。放越多，找規則越慢、越容易混亂。

  • 執行前先 Plan 的規則
  • 語言與程式碼偏好
  • 檔案管理規則
  • LINE 推播 / GitHub Pages 流程
SETUP.md
設定抽屜

只在換電腦、排錯、重建環境時才需要打開。平時不佔空間、不干擾。

  • 換電腦還原步驟
  • Skills 安裝指令
  • LINE Bot 架構與排錯
  • Status Line 設定細節

運作原理

Claude 每次對話的記憶體是有限的。放越精準，回應越快越準。
